# GRAPHITE — детейлинг и онлайн-запись

Мобильный сайт детейлинг-студии: услуги, свободные окна, заявка клиента и кабинет мастера с графиком работы.

**Демонстрация:** https://insolent77.github.io/avto/

## Что реализовано

- Адаптивный тёмный интерфейс, студийное изображение автомобиля и индивидуальные SVG-иконки.
- Плавные переходы, появление секций, интерактивная навигация и три шага записи. Поддерживается `prefers-reduced-motion`.
- Выбор услуги, даты и времени, создание и отмена заявки, добавление в календарь.
- Кабинет мастера: подтверждение, завершение и отмена заявок, рабочая неделя и отдельные выходные.
- Отдельный Node.js / SQLite сервер: общие записи между устройствами, пароль мастера, защита клиентских записей токеном, атомарное резервирование трёх боксов с учётом длительности.

## Режимы

**GitHub Pages публикует только `dist/`.** Это демонстрация: данные находятся в браузере посетителя, демо-кабинет открыт. Вводите вымышленные контакты. Заявки не передаются между устройствами.

**Серверная версия** запускается через `server.mjs`. Общая база SQLite хранится на сервере; для мастера требуется пароль. GitHub Pages не запускает этот backend. Для реальной работы разместите приложение на отдельном Node.js-хостинге или VPS, например через подготовленный Docker Compose.

## Запуск

Нужен Node.js 24+. Внешних npm-зависимостей нет.

```sh
git clone https://github.com/Insolent77/avto.git
cd avto
```

Демонстрация: `node preview.mjs` → http://127.0.0.1:8788

Сервер: скопировать `.env.example` в `.env`, задать уникальный `OWNER_PASSWORD` длиной от 16 символов и `NODE_ENV=development` для локального HTTP. Затем:

```sh
node --env-file=.env server.mjs
```

Открыть http://127.0.0.1:8787. Значок профиля открывает кабинет мастера.

Проверки: `npm test` — 12 проверок бронирования, одновременных заявок, доступа и графика.

## GitHub Pages

В Settings → Pages источник публикации — **GitHub Actions**. Workflow `.github/workflows/pages.yml` проверяет исходники, запускает тесты и публикует только `dist/` после push в `main`.

Веб-ресурсы и manifest используют относительные пути, поэтому сайт работает в `/avto/`. Серверные файлы, переменные окружения и базы данных не входят в артефакт Pages.

## Настройка под студию

- `dist/business.json` — название, описание, услуги, цены, длительность и число боксов.
- `dist/style.css` — базовые контролы; `dist/design.css` — визуальная тема.
- `dist/motion.js` — иконки, переходы, анимации и режим уменьшения движения.
- `dist/assets/studio-hero-v2.png` — AI-визуализация, не реальные работы студии. Источник и промпт: [DESIGN.md](DESIGN.md).
- `dist/manifest.webmanifest`, `dist/icon.svg`, `dist/index.html` — метаданные и иконка.
- [SETUP.md](SETUP.md) — подробный запуск и передача клиенту.
- [ACCEPTANCE.md](ACCEPTANCE.md) — фактически выполненные проверки.

Первая версия рассчитана на один бизнес, московское время и услуги в пределах одного рабочего дня. Нет автоматических уведомлений, AI-чата, онлайн-оплаты и многодневных работ. Перед приёмом реальных клиентов настроить хостинг, документы обработки контактов, резервное копирование и проверить запись с двух устройств.
