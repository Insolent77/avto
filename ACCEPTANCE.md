# Выполненные проверки

6 ноября 2026 года.

- Проверка синтаксиса `server.mjs`, `dist/app.js`, `dist/domain.js` — успешно.
- `npm test` — 12 проверок, 12 успешно. Реальный HTTP API и временная SQLite: вход, неверный пароль, конкурентная запись на три бокса, повтор запроса, серверные цена и длительность, защита записи токеном, недоступность чужих контактов, пересечения и смежные интервалы, подтверждение мастером, отмена и освобождение, выходной без потери записей, некорректные даты/график, cross-origin запрос, выход из кабинета. В отчёте Node несколько утверждений входят в одну проверку.
- Через браузер при ширине 390 px: главная, выбор услуги, дата, свободный слот, контакты с вымышленными данными, создание демо-заявки, её появление в кабинете, подтверждение — успешно.
- Внешнее фото загрузилось при проверке. Текущая фотография является иллюстрацией, не работой реальной студии.

Не проверено: реальный сервер клиента и домен, Docker Compose, резервное копирование на живом сервере и восстановление, доставка уведомлений (не реализована), физические iPhone/Android и установка, публичный доступ потенциальных клиентов. Браузерный сценарий выполнялся в демо-режиме; серверный сценарий проверен отдельными HTTP integration-тестами, а не объявлен проверенным на двух физических телефонах.
